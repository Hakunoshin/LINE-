# カレンダー候補日コピー（Chrome拡張）

Googleカレンダー（週表示 / 日表示）の時間グリッド上でドラッグして時間帯を選択 →
「9月8日(火) 15:15-18:45」のようなテキストにまとめてワンクリックでコピー、または
選んだ枠をそのまま **Googleカレンダーの予定として登録** できる拡張機能。

実際のカレンダーの予定・空き状況・タイトルは読み取らない。画面上の日付ヘッダーと、
アクセシビリティ上の時間グリッドの座標だけから日時を組み立てる。Googleカレンダー内部の
不安定なクラス名には依存しない。

## 導入方法

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダ
   (`calendar-slot-copier`) を選択
4. Googleカレンダー（calendar.google.com）を開き、**週表示か日表示**にする
5. ツールバーの拡張機能アイコンをクリック → 右上にパネルが出現
6. 時間グリッド内を縦にドラッグ → 緑のボックスが追加される（グリッド外のカレンダー操作は通常どおり）
7. 緑のボックスをクリックすると削除
8. パネルの「コピーする」でクリップボードにまとめてコピー
9. パネルの「カレンダーに登録」で、選んだ枠をGoogleカレンダーの予定として登録（後述）
10. 「終了」で選択をリセットしてパネルを閉じる

## Googleカレンダーへの登録（予定を自動作成）

「候補日」テキストを作るだけでなく、選んだ枠を **Google Calendar API で実際の予定として作成**
できる（内容確認や保存ボタンの操作は不要で、そのままカレンダーに入る）。

- パネル上部の見出し入力欄（初期値 `【候補日】`）が、そのまま**予定のタイトル**になる。
  空欄のときは `予定` というタイトルになる。
- 一覧の各行にある **📅ボタン**で、その1件だけを登録する。
- フッターの **「カレンダーに登録」ボタン**で、選択中のすべての候補を一括で登録する。
- 予定は主カレンダー（primary）に作成する。カレンダーの読み取りは行わず、書き込みのみ。
- 日時はブラウザのタイムゾーン（`Intl` で自動判定、取得できない場合は `Asia/Tokyo`）付きで
  送るため、選んだ壁時計時刻どおりに作成される。

### 初回セットアップ（OAuth クライアントID）

他人のカレンダーに書き込むには Google の OAuth 認可が必須なので、初回だけ設定が必要。
（設定しなくても「予定作成画面をタブで開く」方式で代用できるが、その場合は保存操作が必要。）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを用意し、
   「APIとサービス」→「ライブラリ」から **Google Calendar API** を有効化
2. 「OAuth同意画面」を設定し、テストユーザーに自分のGoogleアカウントを追加
3. 拡張機能のパネルで **⚙ Google連携設定** を開くと「承認済みのリダイレクトURI」が表示される
   （`https://<拡張機能ID>.chromiumapp.org/` の形。拡張機能IDは `chrome://extensions` で確認可）
4. 「認証情報」→「OAuthクライアントID」→ 種類 **ウェブアプリケーション** を作成し、
   **承認済みのリダイレクトURI** に 3 の値を登録する
5. 発行された **クライアントID**（`xxxx.apps.googleusercontent.com`）をパネルの入力欄に貼って「保存」
6. 以降「カレンダーに登録」を押すと、初回はGoogleの同意画面が出て、許可後は自動で予定が作成される

- 認証で得るのはアクセストークン（約1時間で失効）のみ。失効時は自動で取り直す。
- OAuth未設定・認証拒否・API失敗のときは、**予定作成画面をタブで開く方式**にフォールバックする。
  複数件でポップアップがブロックされた場合は、calendar.google.com のポップアップを許可するか、
  各行の📅から1件ずつ開くとよい。

## 動作条件・制約

- 日本語表示のGoogleカレンダーの週表示・日表示に対応する。
- 日付ヘッダーと時間グリッドの整合性を確認できない場合は、誤った日時を選択せず、パネルに理由を表示する。
- スクロール、サイドバー開閉、画面サイズ変更、表示切替が起きた場合は座標を再計測する。
- 開始時刻は15分単位で切り捨て、終了時刻は切り上げる。短いドラッグでも最短15分の候補になる。
- 重複または連続する同日の選択枠は、自動的に一つの枠にまとめる。

選択位置がずれる、または検出できない場合は、パネルの「検出結果をコピー」から出力される
日付・座標情報を添えて知らせてください。予定名や予定内容はこの情報に含まれません。

## ファイル構成

- `manifest.json` — Manifest V3設定（`identity`/`storage`権限、googleapis へのhost権限）
- `background.js` — アイコンクリックのトグル通知、OAuth認証、Calendar APIでの予定作成
- `content.js` — オーバーレイ描画・座標推定・パネルUI・クリップボードコピー・カレンダー登録
- `content.css` — パネル/オーバーレイ/選択ボックス/設定UIのスタイル
